# Django Monthly Challenges Example

A Django project for hosting a monthly challenges website.

## Requirements

- Python 3.10
- Django 4.0

## Installation

To set up the project, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/PartORG/Django_Monthly_Challanges_Example.git
   cd Django_Monthly_Challanges_Example
   ```

2. Create a virtual environment and activate it:
   ```sh
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. Install the dependencies:
   ```sh
   pip install Django==4.0
   ```

## Usage

To run the project, execute the following command:

```sh
python manage.py runserver
```

This will start a development server on `http://127.0.0.1:8000/`. You can then access the monthly challenges website by visiting this URL in your web browser.
